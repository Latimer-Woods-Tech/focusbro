# FocusBro — founding-cohort distribution record

The distribution loop is founder story → tagged challenge → word → delivered
check-in → outcome → return. Views are not wins; retained accountability is.

## Canonical experiment

Campaign: `founder-cohort-01`. Use `npm run growth:link --` with a platform
source (`tiktok`, `reels`, `shorts`), the campaign, content ID, and challenge.

| Content | Demonstration | Challenge |
|---|---|---|
| `01-origin` | “I built reminders and swiped them away” | `open-email` |
| `02-cant-swipe` | The real check-in arriving | `open-document` |
| `03-dogfood` | Founder gives a real word | `send-outreach` |
| `04-not-yet` | Honest “not yet” → warm reschedule | `ten-minute-tidy` |
| `05-proof` | Kept-word outcome and next step | `start-assignment` |

Example:

```sh
npm run growth:link -- --source tiktok --campaign founder-cohort-01 \
  --content 02-cant-swipe --challenge open-document
```

## Operating protocol

1. Publish all five within seven days; repost a creative with a different source,
   never a different content ID.
2. Observe ten people without coaching the flow. Record only timestamps and
   friction categories in a private workspace—never tasks or contact data here.
3. Every Friday, open the founder scorecard on `/me/` and compare visits,
   distinct-user activation, delivery, kept-word rate, D1, and D7.
4. At 20 visits: activation below 10% means rewrite hook/CTA; 10–25% means test
   the landing promise; above 25% earns more traffic.
5. Delivery below 95% blocks promotion. Fix the channel before judging demand.
6. At ten D1-eligible users: below 30% means fix task choice, timing, or check-in
   response; do not answer weak retention with new tools.
7. Scale only creatives producing activation and return. Archive vanity winners.

Founder-gated inputs: authentic footage, publication, participant recruiting,
and interviews. Codex owns links, instrumentation, scorecard, and release safety.
