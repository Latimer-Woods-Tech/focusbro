## Lessons learned

1. **Migration correctness needs a runtime-query contract.** Applying an empty
   migration chain alone did not reveal that sync code referenced
   `sync_logs.data_size` and `devices`; the explicit fresh-D1 queries in CI now
   guard those exact dependencies.
2. **A passing deploy is not final evidence.** Verify
   `https://focusbro.net/health` with a unique query string and require the
   exact merged `build_sha`. Edge propagation may briefly return the prior
   build even after GitHub deploy succeeds.
3. **Browser journeys find product defects that route tests miss.** The first
   recovery journey showed that `Not yet` recorded a miss and then erased its
   confirmation during refresh. The browser contract now protects the intended
   no-shame behavior.
4. **Inline DOM templates require a sink audit.** Browser-local input can still
   become executable when restored from localStorage and interpolated into
   `innerHTML`. Escape values at every dynamic sink and keep a browser proof.
5. **Retire compatibility only from evidence.** Read-only production D1 counts
   found one legacy session credential and one legacy SHA-256 password hash.
   The legacy auth bridge must stay until both counts reach zero.
6. **Do not let historical docs steer current operations.** The old architecture
   snapshot claimed secrets and deploy failures that no longer existed. Current
   architecture and debt state now live in canonical documentation; historical
   records remain archival only.
